외래 명세서(서식 031) 기준 · 명세서 1건당 총진료비

월별 호흡기 외래 명세서 수

겨울(11~3월)에 약 2배로 늘어납니다. 감염성 상병은 ICD 기준 J00~J22(급성 호흡기 감염, 독감, 폐렴 포함)입니다.

소득 5분위별 진료비 — 호흡기

분위가 올라가도 진료비는 거의 같습니다. 의료급여는 분위가 없어 따로 표시합니다.

소득 5분위별 진료비 — 호흡기 외 (비교)

호흡기가 아닌 외래도 마찬가지로 분위 간 차이가 작습니다.

월별 소득 격차: 5분위 ÷ 1분위 진료비

1.0이면 두 분위의 진료비가 같다는 뜻입니다. 두 분위 중 한쪽의 월 건수가 건 미만이면 선을 끊습니다.

의료기관 종별 진료비

같은 호흡기 외래라도 상급종합병원이 의원의 약 3배입니다.

종별 × 권역

칸 안은 선택한 금액(원), 아래 작은 숫자는 건수. 건수가 부족한 칸은 빗금입니다.

상병별 소득 격차 (외래, 건수 상위 15)

같은 상병 안에서 1분위와 5분위의 평균 진료비를 비교합니다. 점이 1.0 선에 가까울수록 격차가 없습니다.

소득 5분위 표 보기
  • 출처: 실습 데이터 — 명세서·수진자·요양기관은 가상, 상병마스터·코드표는 건강보험심사평가원 공개 자료.
  • 소득은 건강보험료 5분위(대리변수)이며 의료급여 대상자는 분위가 없습니다. 의료급여 진료비는 합성 데이터 생성 방식의 영향으로 일반의 약 20% 수준으로 나타납니다.
  • 연령·성별은 보정하지 않았습니다. 관찰된 차이이며 원인을 뜻하지 않습니다. 요양기관 이름이 없어 개별 병원 비교는 할 수 없습니다.
  • 호흡기 입원 명세서는 건뿐이라 분석에서 제외했습니다.
